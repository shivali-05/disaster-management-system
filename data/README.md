# Data Management & Storage Foundation

This directory manages the storage, metadata, contracts, and sample representations of datasets used across the Multi-Hazard Risk and Infrastructure Assessment pipeline.

---

## Directory Overview

- **`raw/` (`data/raw/`)**: Stores immutable, unprocessed source satellite datasets (e.g., LoveDA for semantic segmentation, xView for object detection, and raw case study imagery). Files here are strictly read-only and must never be altered in-place or committed to version control.
- **`processed/` (`data/processed/`)**: Contains prepared, training-ready dataset representations (e.g., tiled images, converted YOLO label files, and split subsets). These artifacts are deterministically generated by pipeline preparation scripts.
- **`metadata/` (`data/metadata/`)**: Contains lightweight data contracts, schemas, class mappings, dataset manifests (`*.csv`), and summary statistics. These files define the exact subset selections and data contracts across components.
- **`samples/` (`data/samples/`)**: Houses small, lightweight representative samples of imagery and masks used for quick smoke-tests, validation pipelines, and documentation.

---

## Git & Storage Policy

1. **Large Data Exclusion**: All raw imagery datasets, large processed image tiles, temporary artifacts, and model checkpoints are strictly excluded from Git via `.gitignore`.
2. **Tracked Artifacts**: Only lightweight metadata contracts (`class_mapping.json`, `feature_schema.json`), dataset manifests, configurations (`configs/data.yaml`), documentation, and directory anchors (`.gitkeep`) are tracked.
3. **No Overwrites**: Raw source data is preserved in its original form to ensure reproducibility.

---

## High-Level Data Flow

```text
Raw Imagery & Labels (LoveDA / xView / Case Studies)
                   ↓
        Validation & Inspection
                   ↓
Manifest Generation & Controlled Subset Selection
                   ↓
 Runtime / Prepared Preprocessing (Tiling & Augmentation)
                   ↓
        Computer Vision Inference
  (Semantic Segmentation / Object Detection)
                   ↓
 Feature Extraction (feature_schema.json Contract)
                   ↓
             Risk Engine
                   ↓
        Explanation & UI Dashboard
```
